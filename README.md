# MXW01 Web Terminal

Онлайн-студия печати для термопринтеров: чеки, лента, ценники и изображения — целиком в браузере, без установки приложений. Живёт на [mxw01.online](https://mxw01.online).

## Возможности

- **Текст** — быстрый набор с эмодзи, печать на чековых принтерах (ESC/POS).
- **Лента** — конструктор ленты: текст, QR/штрих-коды, разделители, встроенные инструменты (списки, календарь, привычки, замены и другие).
- **Ценники** — шаблоны розничных ценников: скидка, старая/новая цена, копии.
- **Изображения** — подготовка фото под термопечать: ресемплинг, яркость/контраст, дизеринг.
- **Принтеры** — MXW01 по Web Bluetooth, POS-принтеры по WebUSB, HPRT HM-T260LR по BLE (TSPL/ESC-POS).
- **PWA** — установка на телефон/ПК, офлайн-режим, проверка обновлений прямо с сайта.

## Обновления

Каждая версия публикуется [релизом](https://github.com/Sayikoro/https-mxw01.online/releases) с тегом `vX.Y.Z`; к релизу приложен `mxw01-deploy-kit.zip` — он устанавливается через админ-панель `/update` на хостинге сайта. Кнопка «Проверить обновления» на сайте сама сверяет установленную версию с последним релизом.

## Сборка из исходников

Стек: Next.js 16 + React 19 + TypeScript + Tailwind 4. Печать выполняется целиком на клиенте (Web Bluetooth / WebUSB), серверная часть минимальна.

```bash
bun install
bun run dev   # http://localhost:3000
```
